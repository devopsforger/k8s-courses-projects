# K8S-310 project pack

Ten student-facing project Markdown files (with YAML frontmatter) and ten instructor solution Markdown files. All use a separate TaskForge starter application; see `taskforge-starter.zip` distributed alongside this pack. Do not publish instructor solutions as student challenges.

**Important:** Reference manifests and commands are educational examples. Some exercises require a separately provisioned database, ingress controller, CNI, or StorageClass. Test each exercise in your chosen environment before release.
